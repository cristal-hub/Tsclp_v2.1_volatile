# Tsclp_v2.1_volatile — скальпинг-робот с выбором топ-10 волатильных акций

## ⚠️ Только песочница. Реальные сделки запрещены.

## Отличия от Tsclp_v2.0
- Инструменты **не фиксированы**. Скрининг выбирает **топ-10 волатильных** акций MOEX.
- Фильтр ликвидности: средний дневной оборот ≥ 10 млн ₽.
- Кэш скрининга: 24 часа.
- Если скрининг не удался — `uncertain_state=True`, новые входы запрещены.
- Fallback на SBER/GAZP **отключён**.

## Запуск
1. Скопируйте папку `Tsclp_v2.0` → `Tsclp_v2.1_volatile`.
2. Замените `config.py`, `main.py`, `README.md`. Добавьте `screener.py`, `tests/test_screener.py`.
3. Создайте venv: `python -m venv venv`.
4. Активируйте: `.\venv\Scripts\Activate.ps1`.
5. Установите: `pip install -r requirements.txt`.
6. Заполните `.env` (числа вместо заглушек).
7. Запустите тесты: `.\run_tests.ps1`.
8. Запустите робота: `python main.py`.

## Ограничения
- Скрининг делает много запросов к API. При 200+ акциях — несколько минут.
- 10 инструментов ≠ 10 позиций. Риск-менеджер ограничит одновременные позиции.
- Прибыльность не подтверждена.
